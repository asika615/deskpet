# Reference Companion v0.3.16

入口 `figure.json`。在 Coopanion 的装扮页导入整个形象包 ZIP，或选择本目录。请勿只导入 `figure.json`。延续 v0.3.15 的按需载入，并降低动态表情绘制与上传成本。

表情控制器仅预载中性表情与必需的眼部素材；其他表情首次使用时异步加载，加载期间暂用中性表情。原图、PNG、模型和动作没有更改。动态头部纹理从 1206×1304 降到 603×652，但桌面显示尺寸不变；静态头部底图与各表情特效不随眼神重复生成。首次使用某个表情可能有短暂延迟。

软件组件测试与 v0.3.15 对比：模拟 120 帧眼神转移和眨眼，头图上传从 99 次降至 22 次、平均帧耗时约 61.6 ms 降至 5.4 ms（测试机器的纯软件路径，不能直接等同于 Electron 帧率）；单次纹理上传像素降至四分之一。半尺寸头图与旧图降采样后的单个示例平均 RGBA 通道误差为 0.105/255，仍需实际屏幕观感验收。详见 `verification/performance-validation.json`。

若连内置 Coo 也显示失败，先重启 Coopanion 并单独测试内置形象；本包的优化无法修复应用渲染器或 GPU 的独立故障。建议在设置中关闭帧率锁定并使用 30 帧。
