# v0.3.18 全动作双臂修复候选版

本轮直接基于用户上传的 v0.3.17。新增 arm-motion.js 为近侧、远侧各自驱动肩→肘→腕，重写走跑、跳跃、小跳、挥手、拖拽、舞蹈、颤抖、拍动和五种原有情绪的关节配合。短头部手势保留安静支撑，不强加新手势。

走跑读取宿主真实腿部步相；hop 保存动作意图以区别 jump。动作切换保留当前角度和速度，以临界阻尼平滑收敛。greet 显式映射到 wave。表情动作仅在安静状态叠加，不再覆盖移动／拖拽姿态。

所有 PNG、model.json、pivot、头颈、表情、服装和白色板甲绑定均不变。未扩肩、未增加肤色、未添加新的遮挡片。已有隐藏袖根连接场不再重复跟随头发／领口，保留衣身与上臂之间的局部过渡。

导入：将此包 ZIP 导入 Coopanion 覆盖同 ID 旧版，完全退出后重启。preview.html 需 HTTP 服务，使用与导入相同的工厂路径。

每项实际运行原生 body 逻辑 288 次更新，保留宿主整身旋转、镜像、缩放、跳跃高度及释放阶段；每项输出前后各 96 帧、七关键帧、双臂近景和视频。完整资料在恢复包 review/all-arms/index.html。

限制：真实 Coopanion / 浏览器 WebGL / Electron 窗口验收未完成。本地 Chromium 在启动时 SIGTRAP，云浏览器无法访问本地服务且拒绝 file://。现有视频来自原生动作逻辑驱动的软件光栅化，不是窗口录屏，不能替代实机验收。
