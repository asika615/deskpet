# v0.3.11 头颈衔接与工作区交接

本次以用户上传的 v0.3.10 为稳定基线。原立绘与工程 original.png 完全相同，未替换美术基准。

## 修复结果

| 验收问题 | 修改前 | 当前处理 |
|---|---|---|
| 头是否像架在脖环上 | 平直脖环边缘与下方立领分层清楚 | 使用原立绘脖环形状，上缘嵌入原下巴/侧发的遮挡范围 |
| 脖环是否像独立圆筒 | 上下完整横边，下面接细窄直筒 | 取消独立直筒的长段读法，脖环下缘转入短领口接缝 |
| 下缘是否还有一截可读出的脖子 | y≈699..737 的深色立领约38像素 | 重新注册为原图中央领口，y=710..737映射为696..708，连接段约12源坐标像素 |
| 上身能否承接头部 | 上胸织物出现得较晚，领口两侧缺少连续承接 | 局部抬升上胸顶端，增加两侧简洁Q版连接底色并埋入原肩部与板甲后 |

这些是图集与局部网格的源坐标值，不是移动 Head 的数值，也不代表所有动作帧中的可见像素长度。完整脖环仍保留原设的黑色带与银扣，减少独立零件感来自遮挡、连接段合并与上身承接，而非继续把环削成细线。

## 保留与范围

- Head 全局参数仍是 scale=1、dx=0、dy=0。头部轮廓、耳朵、发型、五官和表情管线未改。
- wave 肩肘腕、肩部形变、手部轨迹、板甲、外套与其他部件注册未改。
- 181 个 PNG 文件与基线逐字节相同；源像素由原图与现有贴图在运行时局部组装。
- 新增 collar-connection.js；figure.js 接入局部图集合成和 deformer；model.json 只改变 torso 的父级/网格与修复说明。另更新版本元信息、预览说明、资源清单和验证报告。
- 原图的肩部皮肤不会复制进身体。领口两侧由可编辑的简单原生 Canvas 曲线做底层承接，不新增肌肉、锁骨或写实皮肤阴影。
- 胸口、服装的既有精细化风格与原始平涂立绘仍有差异，保持现有成果，本次未重绘整套服装。

## 验证与限制

已用生产 figure、表情与形变代码对照480帧，涵盖完整挥手、点头、鞠躬与视线变化；原有部件顶点哈希及肩肘腕坐标与 v0.3.10 完全一致。颈口网格无翻转，作用范围外17496个采样点位移为零。20种表情×3种眨眼值×2种说话值，共120组，输出像素哈希与基线一致。

最终图直接取自实际组件。idle、50% lift、100% lift 是既有动作系统的冻结采样，并未改变动作参数。软件光栅化不等同于 WebGL 的纹理过滤与抗锯齿，也不构成 Electron 导入验证。

## 固定工程与恢复

项目统一放在 coopanion-workspace/，包含 v0.3.10、v0.3.11、原立绘、CURRENT.md、project.json、检查工具、最终对照图和本报告。相对路径可随完整目录迁移。

python3 start-preview.py 启动当前版本预览；python3 tools/check-workspace.py 检查文件摘要。开发复查工具需要 Node.js、@napi-rs/canvas 与 Python Pillow；桌宠运行不依赖这些开发工具。

快照不锁定运行环境，也不能保证新会话自动获得文件权限。它提供完整可恢复的工程交接，避免只剩旧路径或文字记录。
